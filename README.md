# Ecommerce-Sales-Prediction
电商商品销量预测与促销效果分析

一、项目简介
本项目为“Python 人工智能程序设计实践”课程项目（A18 选题）。

我们利用 Python 对电商历史销售数据进行深度分析与建模，旨在通过机器学习模型预测未来销量，并分析价格、促销、节假日等因素对销售的影响，从而提供科学的库存备货建议。

三、技术栈

编程语言：Python 3

数据处理：Pandas, NumPy

可视化：Matplotlib, Seaborn

机器学习：Scikit-learn, XGBoost

时间序列分析：Statsmodels

四、核心任务流程

1、数据预处理：清洗 约18万条 Kaggle 电商零售数据，处理缺失值与异常值。

2、特征工程：构造滞后特征、滚动窗口特征、节假日及促销标记。

3、数据可视化：绘制销量趋势图、因素关联热力图等，分析销量与各维度的关系。

4、模型评估对比：对比不同回归模型，使用 MAE、RMSE、R² 作为核心评价指标。

五、项目结构说明

/data 文件夹：存放原始及清洗后的数据集（如 clean_data.csv）。

/scripts 文件夹：存放数据清洗 (data_clean.py)、模型训练 (model.py) 等核心脚本。

/figures 文件夹：存放 EDA 过程中生成的各类可视化图表。

/docs 文件夹：存放技术报告（PDF）及答辩 PPT。
